# KIMM 도메인 문체

보고서체를 사용하고 문장은 `-다`로 종결한다.

금지표현은 다음과 같다.

- `것 같다`
- `것 같습니다`
- `아마도`
- `어쩌면`
- `최고`
- `최대한`
- `무한`
- `etc`
- `etc.`
- `할 예정`

근거 없는 최상급, 추측, 미래의 막연한 약속을 쓰지 않는다.

그림 인용은 그림을 문장의 주어로 세우지 않는다. `그림 N은 …를 나타낸다` 대신, 단락의
목적을 뒷받침하는 주장 문장을 쓰고 그 근거로 그림을 문장 끝 괄호에 표기한다 —
`…하는 구조를 개발한다 ([[FIG:…]]).`
