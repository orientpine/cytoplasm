# 새 도리 설치는 처음부터 herdr로 깔리고, aoe·tmux로 쓰던 도리는 안내서 하나로 옮길 수 있습니다

## 바뀐 것

- 도리 설치기(`python3 -m automation.install.dori`, 마법사·quickstart 의 「도리」)의 기본 backend 가 aoe 에서 **herdr** 로
  바뀌었습니다. 아무 옵션 없이 돌리면 herdr 0.9.5 와 웹 터미널 ttyd 1.7.7 을 sha256 확인 뒤 깔고, herdr 서버
  (`dori-herdr.service`)와 웹(`herdr-web@8181`, 자기 비밀번호)을 사용자 유닛으로 켜고, 리드를 herdr pane 에 띄워
  `leadPane` 에 적습니다. root 는 필요 없습니다. 받는 바이너리와 sha256 은 `dori/herdr.toml` 한 곳이 정합니다.
- aoe 길은 남아 있습니다: `--backend aoe` 는 예전처럼 aoe 예시 설정만 복사하고 herdr 를 건드리지 않습니다.
- 이미 깔린 계정에서 다시 돌리면 config·역할 지침·웹 설정은 덮지 않고, 옛 aoe 웹이 쓰는 포트도 빼앗지 않습니다.
- 도리 포크 962727c: herdr 위에서 레인·리드/레인 교대·감시 sweep·죽은 창·리드 되살리기·session-watch 가 돌고
  (포크 #287·#288·#290), 브라우저로 같은 주소·같은 비밀번호로 보는 herdr 웹(#291, aoe 없이 깐 계정은 자기 비밀번호 #298),
  교대가 옛 리드를 얼리기 전에 옛 감시를 끝냄(#292),
  웹 맨 위에 탭마다 omo 상태(working·waiting·idle·none) 막대와 열면 리드 탭이 앞(#293), 레인이 준비되면 거절됐던 리드 교대를
  같은 승인으로 다시 시작(#299), 체크포인트 명령(#297).

## 사용자에게 보이는 변화

- 새로 까는 사람: 설치가 끝나면 `http://127.0.0.1:8181` 웹에서 리드 탭이 보이고, 맨 위 막대에 탭마다 omo 가 일하는지·기다리는지가 나옵니다. 비밀번호는
  `~/.config/herdr/web-8181.env` 의 `HERDR_WEB_PASSPHRASE` 입니다. 테일넷 주소로 열려면 `--web-origin` 을 줍니다.
- aoe 로 쓰던 사람: 이 릴리스를 받는 것만으로는 아무것도 바뀌지 않습니다. 옮길 때만 아래 안내를 따릅니다.

## aoe·tmux 로 쓰던 도리를 herdr 로 옮기기 (따로 읽을 안내)

안내서: [docs/guide/herdr-전환.md](../guide/herdr-전환.md) — 이 안내서 하나만 보고 끝낼 수 있게 썼습니다.
순서는 백업 → 포크를 새 고정 커밋으로 → 설치기 다시 돌리기 → backend herdr → 리드 교대 → `DORI_LEAD_*` 지우기 →
감시 확인 → 웹을 같은 주소의 herdr 웹으로 → 재시작 확인이고, 마지막에 한 줄 되돌리기가 있습니다(옛 리드는 24시간 얼려 둠).
가장 쉬운 길은 리드에게 "herdr 로 옮겨. 사이토플라즘 docs/guide/herdr-전환.md 순서대로" 라고 쓰는 것입니다.
옮길지는 쓰는 사람이 정합니다. 앞으로 도리는 herdr 판만 고쳐 나갑니다.

## 깨지는 변경·운영자 할 일

- 깨지는 변경 없음. 설치 기본값만 바뀌었습니다. aoe 로 새로 깔던 자동화는 `--backend aoe` 를 붙입니다.
- 이 릴리스로 노드에서 할 일은 없습니다. 도리 이전은 쓰는 사람이 안내서로 합니다.
