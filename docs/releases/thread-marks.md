# 스레드 이름 앞 표시가 "누구 차례인지" 하나로 바뀌었습니다

## 바뀐 것

- 소유자가 고른 표시(2026-11-03 Q474): 🔄 도리가 하는 중 / 🔔 소유자 응답 필요 / ✅ 됨 / ⛔ 취소 / 💤 새 걸로 바뀜·거둠(답 없이 접음) / ❗ 실패(소유자 차례) / 📌 상시. ⏸️는 더 쓰지 않습니다.
- 스레드 이름 앞 표시는 늘 하나입니다. "✅ ❗ 실패 · …", "⛔ 취소 · 🔄 …"처럼 두 표시가 겹치던 이름은 다음 이름 바꾸기 때 하나로 정리됩니다. 종류 이모지(✉️ 🔐 📬)는 그 뒤에 남습니다.
- 유돌 메일: 한 메일은 첫 스레드에서 끝납니다. 고쳐 쓴 초안도 같은 스레드에 올라오고, 메일 전문은 그날 다이제스트 스레드에 둡니다(#225).
- 도리 포크 6954d4c: 문지기의 🔐 승인 카드 스레드가 🔔로 열리고 끝나면 표시 하나(✅ ⛔ 💤 ❗)만 붙음, 다른 사람에게 주는 공유가 대기 중인 공유를 대체하지 않음(포크 #317). 그리고 표시 규칙. 우리 답 뒤 일하는 레인이 없으면 🔔가 되고, 소유자가 🔔·❗ 스레드에 답하면 🔄가 됩니다. ⛔·💤도 끝난 스레드로 보고 보관합니다(포크 #315).

## 사용자에게 보이는 변화

- 디스코드 스레드 목록에서 맨 앞 표시 하나로 소유자 차례(🔔·❗)인지, 도리가 하는 중(🔄)인지, 끝났는지(✅·⛔·💤)를 압니다.

## 깨지는 변경·운영자 할 일

- 깨지는 변경 없음. 옛 이름(⏸️, "✅ 완료 · " 같은 끝 말)도 그대로 읽고 다음 이름 바꾸기 때 새 표시로 바꿉니다.
