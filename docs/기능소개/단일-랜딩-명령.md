# 단일 랜딩 명령 (DG-1 B · DG-6)

## 무엇을
`automation/land.sh` 하나로 **push → 노드 런타임 수렴 → 사후 검증**을 원자적으로 수행한다.
방금 push한 sha가 **실제로 프로덕션에서 돌기 전까지** 종결하지 않는다.

"프로덕션이 무엇인가"는 노드가 판정한다(DG-6):

| 노드 상태 | 프로덕션 | 상주 체크아웃(`/srv/autophagy-agents`) |
|---|---|---|
| `current` 심링크 살아 있음 = **릴리스 모드** | 불변 릴리스 | 관측소일 뿐 → dirty/ahead는 **경고** |
| `current` 부재 = **폴백 모드**(`rm` 롤백) | 상주 체크아웃 | 프로덕션 그 자체 → dirty/ahead는 **차단** |

## 왜
반복되는 드리프트는 "두 단계를 하나로 하다 한쪽을 빠뜨리는" 사고다: push하고 나서 노드 동기화를
잊으면 프로덕션이 낡은 코드를 돈다(2026-07-29 실측: ops가 11커밋 뒤처졌고 아무도 몰랐다).

그런데 [불변 런타임 릴리스](불변-런타임-릴리스.md) 이관 뒤에도 옛 계약을 그대로 두면 **반대 방향의
사고**가 난다 — 상주 체크아웃은 더 이상 프로덕션이 아닌데, 거기 남은 다른 세션의 미커밋 편집 하나가
**무관한 랜딩을 거부**한다. 스냅샷 설계가 없애려던 바로 그 결함이다. 그래서 DG-6은 미러를 경고로
낮추고, 하드 사후조건을 **릴리스가 방금 push한 sha에 도달했는가**로 옮겼다.

## 사용 시나리오

### 정상 경로 (릴리스 모드)
1. 워크스테이션에서 `automation/land.sh` 실행.
2. **HEAD가 `refs/heads/main`인지** 먼저 확인하고(아니면 push 전에 중단), dev 체크아웃이 추적-clean이고 origin보다 뒤처지지 않았는지 확인(뒤처졌으면 중단 — 자동 rebase 없음).
3. `git push origin main`(이미 같으면 no-op).
4. **노드가** 자기 런타임 모드와 미러 드리프트를 판정해 돌려준다(워크스테이션에서 `/srv`를 stat하면
   남의 호스트를 보는 셈이라 반드시 노드측 판정).
5. 미러가 clean-behind면 `pull --ff-only`를 **best-effort**로 시도한다.
6. 릴리스를 **내가 push한 sha로 못 박아** 수렴시킨다(`RELEASE_EXPECTED_SHA`).
7. 수렴 후 origin을 **다시 읽어** 그사이 다른 세션이 착지하지 않았는지 확인하고,
   `current --verify <sha>`로 런타임을 최종 확인한다.
8. 라이브 스킬 ABI 스캔(WARN 전용) 후 한 줄 요약:
   `landed: origin/main=… runtime=release@… mirror=… abi=ok`.

### 경고 경로 (릴리스 모드)
- **미러가 dirty하거나 앞서 있으면** → `LAND-MIRROR-WARN` + 헬스체크와 **동일한** 복구 안내
  (`format-patch`; `reset --hard`는 절대 권하지 않는다). 랜딩은 계속된다 — 프로덕션은 릴리스이므로.
- **미러 ff-pull이 실패해도** → 경고. 관측소를 못 맞춘 것이지 착지 실패가 아니다.

### 실패·거부 경로
- **HEAD가 main이 아니거나 detached면** → push 전에 `LAND-BLOCK`. `git push origin main`은 HEAD가 아니라
  로컬 `main` ref를 발행하므로, 다른 브랜치에서 착지하면 남의 미푸시 main 커밋이 **부수적으로 origin에
  발행**된 뒤 사후 검사만 실패한다 — 조작자는 "노드는 그대로"를 읽고 아무 일도 없었다고 믿는다.
  dirty·behind·`dev_head` 검사가 모두 HEAD 기준이라, HEAD를 main에 못 박는 것이 세 검사를 실제로
  push되는 ref에 맞추는 유일한 방법이다. 브랜치 작업은 main에 병합(또는 PR)한 뒤 착지한다.
- **dev가 dirty하거나 origin보다 뒤처졌으면** → push 전에 `LAND-BLOCK`.
- **폴백 모드에서 미러가 dirty/ahead면** → `LAND-BLOCK`. 릴리스가 없으니 그 체크아웃이 곧
  프로덕션이고, ff-pull도 막혀 있다. 앞선 커밋은 `format-patch`로 살려낸다.
- **폴백 모드에서 pull 후에도 HEAD ≠ origin/main이면** → `LAND-BLOCK`(옛 사후조건 그대로).
- **`current`가 깨져 있으면**(끊어진 심링크·심링크 아님) → 거부. "부재"로 넘겨짚으면 릴리스 노드를
  조용히 낡은 미러로 강등한다.
- **push 후 노드 수렴이 실패하면** → `pushed OK to origin/main, but the runtime was NOT converged
  (…). re-run automation/land.sh.` push는 이미 origin에 닿았으므로 유실이 아니다.
- **수렴 중 다른 세션이 착지했으면** → 재확인에서 잡아 거부한다(릴리스가 origin에 없는 sha를
  가리키는 것은 착지가 아니라 분기다).
- **라이브 스킬 ABI 파손** → `LAND-ABI-WARN`(착지는 진행). `LAND_ABI_STRICT=1`이면 블록.

## 주의
- 멱등하다: push할 게 없어도 런타임을 검증·수렴하고 exit 0.
- 드리프트 판정 규칙은 `checkout_mirror_probe.sh` 하나다 — healthcheck는 **탐지**, land는 **수렴**.
  land는 그 함수를 노드에 **값으로 실어 보낸다**(`declare -f`). 노드 사본을 source하면, 방금
  경고로 낮춘 바로 그 미러의 셸을 ops 권한으로 실행하게 된다.
- `git 훅`이 아니라 **추적되는 스크립트**다 — `.git/hooks/`는 미추적이라 clone마다 재설치가 필요하고
  조용히 빠지면 가드보다 위험하다.
