# 개인 서버 대화 채널

## 무엇을

개인 서버의 `#agent-chat`에서 소유자와 Agent가 일반 메시지와 스레드로 대화한다. 채널 응답, 봇을 멘션하지 않은 스레드 응답, 예상 밖 봇의 무응답을 서로 독립한 축으로 검증했다.

## 왜

공급망 승인 전용 `#approvals`와 일상 대화를 섞으면 승인 표면의 의미가 흐려진다. 대화 채널을 분리하면 소유자는 개인 서버에서 자연스럽게 대화하면서도 승인·DM 불변식은 그대로 유지할 수 있다.

## 사용 시나리오

- **채널 대화**: 소유자가 `#agent-chat`에 정해진 응답을 요청하면 Agent가 같은 채널에서 정확히 응답한다. `channel_ack`: green — 실증됨.
- **무멘션 스레드**: 소유자가 채널 메시지의 스레드에서 봇을 직접 멘션하지 않고 요청해도 Agent가 스레드에서 응답한다. `thread_unmentioned_ack`: green — 실증됨.
- **격리 확인**: 두 관찰 창에서 다른 봇의 응답은 없었다. `unexpected_bot`: green — 실증됨.
- **실패 시**: 각 축은 `failed`(검증을 수행했으나 실패)와 `unknown`(검증 미수행·선행 BLOCKED — 실증 주장 없음)을 구분해 기록한다. 한 축의 결과로 다른 축을 추정하지 않는다.
