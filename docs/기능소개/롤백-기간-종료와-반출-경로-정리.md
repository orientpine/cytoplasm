# 롤백 기간 종료 — 옛 반출 경로를 지웠다

## 무엇을

2026-10-07 공개 우선 전환 뒤 되돌리기용으로 남겨 둔 반출 경로를 지웠다. 지운 것은 다음과 같다.

- 반출 스크립트 `automation/public_export.sh`
- 반출 원장 `configs/public-export-manifest.txt`
- 전용 시험 `test_public_export.py`·`test_public_export_release_note.py`
- 운영 매뉴얼의 반출 절차 §1.1~§1.6

옛 개발 저장소 `orientpine/autophagy-agents` 는 archive 되어 읽기 전용으로 남는다.

## 왜

규칙(루트 AGENTS.md 「공개 릴리스 규칙」)은 공개 우선 릴리스가 3회 무사고로 끝나면 이 경로를 지우라고 했다. 실제로는 v1.15.1~v1.20.1 까지 8회가 나갔다. 이전 때문에 생긴 문제(릴리스 적용 통지 누락)는 롤백이 필요한 사고가 아니었고 v1.20.1 로 고쳤다.

남겨 두면 비용이 있었다. 반출 원장은 공개 저장소에 없는 경로만 적고 있어서, 공개 트리에서는 시험이 무엇을 건너뛰는지 가렸다. 실제로 원장이 공개 문서 안의 깨진 링크 38개를 덮고 있었다. 링크가 가리킨 곳은 공개 저장소에 없는 `operations.md`·`docs/patch/*`·일부 기능 소개다.

## 사용 시나리오

- **평소 릴리스**: 달라진 것이 없다. `automation/release.sh` 가 cytoplasm 커밋에 서명 태그와 Release 노트를 만든다.
- **누출 게이트**: `automation/public_gate.py` 는 이제 모든 체크아웃에서 금지 경로와 커밋 메시지를 똑같이 검사한다. "비공개 원본" 분기는 없어졌다.
- **문서 링크 검사**: `test_doc_links` 는 비공개 운영 저장소 경로(`.omo/`·`docs/qa/`)로 가는 링크만 허용한다. 그 밖에 공개 저장소에 없는 문서를 가리키는 링크는 실패로 잡는다. 깨져 있던 38개는 링크를 걷고 이름만 글자로 남겼다.
- **나쁜 릴리스**: 되돌리는 경로는 이제 하나다. 앞으로 나가서 되돌린다(manual-maintainer §5).
