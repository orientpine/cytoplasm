# 유돌이 대시보드 할 일을 완료로 바꾸기

## 무엇을
유돌이 형이 시킨 일을 끝내면 노드 게이트 명령 `todo-done <할 일 id> [--note <메모>]` 하나로 그 대시보드 할 일을
「완료」로 바꾼다. 바꾸는 것은 상태(완료, 진행률 100%)와 선택 메모뿐이고, 사건 기록의 쓴 사람은 항상 「유돌」이다.

## 왜
형이 "이런 거 처리되면 네가 대시보드에서 알아서 완료로 처리해줘"(2026-10-31)라고 했는데, 유돌에게는 할 일을 바꿀 길이
없었다. `order-status` 는 지시만 바꾸고, 대시보드 화면은 유돌 계정에서 닿지 않는다.

## 사용 시나리오
- 정상: 형이 대시보드 할 일에 걸린 지시를 보낸다 → 유돌이 처리한다 → `todo-done pb-0123456789ab-1 --note "지시 9 처리"` →
  노드가 `PROGRESS todo=… status=완료 progress=100` 을 돌려주고 대시보드 파일을 다시 만든다 → 형 화면에서 그 할 일이 완료로 보이고,
  사건 줄에 「유돌 … 완료로 바꿈」이 남는다.
- 이미 완료: 같은 명령을 다시 보내면 아무것도 바꾸지 않고 `ALREADY todo=… status=완료` 를 돌려준다(사건 줄도 새로 안 생김).
- 거절(`YOODORI-GATE-REFUSED`, rc 2): id 가 `pb-<12자리 소문자 16진수>-<번호>` 모양이 아님, `--note` 말고 다른 플래그
  (`--status`·`--by` 등), 메모가 비었거나 200자 초과·여러 줄·셸 문자(`; & | $ ( ) { } * ? !` 따옴표 등) 포함.
  없는 id 는 노드 대시보드가 `PROJECT-BOARD-ERROR no approved todo` 로 거절한다(rc 2).
- 지우기·되돌리기(열림으로)·제목이나 마감 바꾸기는 이 명령으로 할 수 없다.

## 관련
- 코드: `automation/yoodori_gate/yoodori_read_gate.py`(`todo_done`), `automation/project_board/cli.py`
  (`progress --by`, 이미 완료면 `ALREADY`).
- 게이트 기록(`~/.local/state/yoodori-gate.log`)은 `todo-done id=<id> rc=<n>` 만 남기고 메모 본문은 남기지 않는다.
- 승인: 카드 없음. 형 계정 안의 대시보드 쓰기이고, 형이 시킨 일의 결과를 적는 것뿐이다.
