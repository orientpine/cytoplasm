# 기관메일 발신자·전체 폴더·검색

## 무엇을

소유자 DM 다이제스트에는 실제 발신자와 CC를 보여 주되 공유·저장 표면에는 마스킹 값만 남긴다. 받은편지함·보낸편지함뿐 아니라 사용자 폴더까지 읽고, 제목·발신자·본문·스레드·첨부 신호를 조합한 read-only 검색도 제공한다.

## 왜

기존 다이제스트는 실제 발신자를 버려 누가 보낸 메일인지 판단하기 어려웠고, 고정된 두 폴더만 수집해 사용자 폴더의 메일이 검색에서 빠졌다. 대량 공지와 직접 문의의 구분도 검색·답장 판단에 필요했다.

## 사용 시나리오

- **happy path**: 새 메일을 동기화하면 사용자 폴더까지 포함된다. 소유자 DM 카드에는 실제 발신자·CC가 보이고, 검색어는 여러 메타·본문 신호로 결과를 정렬한다. CC-only 수신이나 대량 공지는 불필요한 답장 대상으로 올리지 않는다.
- **보호 경로**: 다이제스트 저장 상태와 공유 로그에는 실제 발신자·CC를 쓰지 않는다. 검색은 읽기 전용이며 compose·send를 호출하지 않는다.
- **배포 확인**: PR #114 merge-commit 착지 후 mail 릴리스가 마운트됐고, 새 검색 모듈을 라이브 payload에서 재조회했다.
