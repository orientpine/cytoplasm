# 메일 첨부 한글 이름

## 무엇을

유돌이 메일 승인 카드에 붙이는 첨부가 한글 이름(예: `과제_행정7_성명.pptx`)으로 카드에 보이고 받는 사람에게도 그 이름으로 간다.
노드에 올릴 때 이름은 지금처럼 영문·숫자로 두고, 메일에 보일 이름만 `stage <이름> --name <표시 이름>`으로 따로 준다.

## 왜

노드 비공개 폴더의 저장 이름은 `[A-Za-z0-9._-]`만 받는다. 그래서 "파일명은 `과제_행정7_성명.pptx` 형식"을 요구하는
제출 메일에 영문 이름(`task_admin7_….pptx`)이 붙었다(2026-10-29). 저장 이름 규칙은 안전을 위해 그대로 두고,
보이는 이름만 따로 받는다.

## 사용 시나리오

- 형: "과제 자료 제출 메일 보내줘" → 유돌: `stage task_admin7_Hong.pptx --name 과제_행정7_홍길동.pptx`
  (파일은 SSH stdin) → `STAGED … display=과제_행정7_홍길동.pptx` → `mail-compose --to … --attachment task_admin7_Hong.pptx …`
  → 카드 첨부 줄에 `과제_행정7_홍길동.pptx` · 크기가 보이고, 형 ✅ 뒤 받는 사람도 그 이름으로 받는다.
- 메일로 받은 첨부(`mail-attachment`)를 새 메일에 다시 붙일 때도 받은 원래 이름으로 나간다(이름 뒤에 크기가 붙은 기록처럼 쓸 수 없는 이름이면 저장 이름 그대로).
- 거절: 표시 이름에 `/`·`\`·`..` 같은 경로, 제어·방향 바꿈·폭 없는 글자, Windows가 못 쓰는 `:*?"<>|`, 점으로 시작, 120자 초과,
  또는 저장 파일과 다른 확장자(`.pptx`를 `.pdf`로)가 있으면 `YOODORI-GATE-REFUSED`로 거절하고 아무것도 저장하지 않는다.
- 같은 저장 이름을 `--name` 없이 다시 올리면 옛 표시 이름은 지워져 새 파일은 저장 이름으로 나간다.

## 어떻게(짧게)

게이트가 `--attachment`로 받은 비공개 파일을 같은 폴더 안 `.named/<내용 해시>/<표시 이름>`에 하드링크로 이어 compose에 넘긴다.
두 발송 경로(기관메일 웹메일 업로드, Gmail `gws -a`)가 모두 파일 이름을 첨부 이름으로 쓰므로, 카드·승인 해시·받는 메일이 같은 이름을 본다.
메일 헤더 인코딩은 각 발송기가 한다: Gmail(`gws`)은 `filename="=?utf-8?B?…?="` 꼴로 넣고, 기관메일은 웹메일 서버가 만든다.

## 관련

- 코드: `automation/yoodori_gate/yoodori_request_runtime.py`(`display_name`·`stage_named`·`named_attachment`), `automation/yoodori_gate/yoodori_read_gate.py`(`stage`, `mail-compose`)
- 시험: `tests/unit/test_yoodori_attachment_display_name.py`
- 승인: 메일 발송은 그대로 형 카드 ✅ 뒤에만 나간다. 이름이 바뀌어도 카드의 첨부 이름·크기·해시가 승인에 묶인다.
