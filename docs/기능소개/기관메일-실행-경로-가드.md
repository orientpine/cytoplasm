# 기능 소개 — 기관메일 실행 경로 가드 (배포됨 ≠ 실행됨)

**완료:** 2026-09-01 · **스킬:** `mail` · **모듈:** `skills/mail/scripts/mail_runtime.py::governed_copy_refusal`

## 무엇을
이 호스트에 관리자 배포본 마운트(`/srv/autophagy-skills/live/mail`)가 있으면, **그 마운트가 아닌 사본**의 mail 스크립트는 mutating 서브커맨드(`draft`·`compose`·`process`·`digest`·`watch`·`confirm`·`discard`·`sign`)를 `GATE-REFUSED STALE-SKILL-COPY-BLOCK …`(exit 3)으로 거부하고 올바른 경로를 알려 준다. 읽기 전용(`mode`·`list-drafts`·`digest-items`·`evidence`)은 막지 않는다. 마운트가 없는 호스트(워크스테이션·단위 테스트)에서는 아무것도 하지 않는다.

## 왜
2026-09-01 원문 인용 릴리스(v1.0.143)가 04:22Z 에 마운트됐는데, 87분 뒤 김경호 박사에게 나간 회신 초안에는 인용이 없었다. Hermes 세션 기록을 보니 에이전트가 `python3 /srv/autophagy-agents/skills/mail/scripts/triage_cli.py draft …` 를 실행했다 — 관측용 미러 체크아웃이지 배포본이 아니다. 그 미러는 08-29 에 누군가 남긴 미커밋 편집 때문에 리컨실러의 ff-pull 이 거부돼 **121 커밋 뒤(#319)에 동결**돼 있었고(승인 정책도 v7), 거기엔 `mail_quote` 가 없었다. 최근 14일 세션 기록에서 스킬 스크립트 호출 308건 중 미러 경로가 90건, 사라진 `~/.hermes/skills/…` 경로 시도가 30건이었다 — SKILL.md 가 SS-1(2026-08-15) 이후 존재하지 않는 경로를 안내하고 있어 에이전트가 파일을 찾아 헤매다 미러를 채택한 것이다. "커밋됨 ≠ 배포됨" 에 세 번째 항이 필요했다: **배포됨 ≠ 실행됨**.

## 핵심 동작 (불변식)
- 판정은 경로 동등성이다: `<live root>/mail/scripts` 를 `resolve()` 한 디렉터리와 실행 중인 스크립트의 실제 디렉터리가 같을 때만 통과한다. 심링크 경로(`live/mail/scripts/…`)로 부르든 릴리스 실경로(`releases/mail/<hash>/scripts/…`)로 부르든 같다.
- live 루트 주입은 `automation.skill_mount.LIVE_ROOT_ENV`(`AUTOPHAGY_SKILL_LIVE_ROOT`) 한 이름뿐이다. 샌드박스 `scenario.sh` 와 e2e actor 는 자기 사본의 루트(`<repo>/skills`)를 선언해 "지금 검사하는 사본이 곧 배포본"임을 밝힌다 — 우회 옵션이 아니라 검사 대상 선언이다. 거부 메시지는 이 변수를 언급하지 않는다.
- 마운트를 읽을 수 없으면 통과가 아니라 거부다(fail-closed) — 배포본임을 증명할 수 없기 때문이다.
- SKILL.md 의 모든 예시 경로가 `/srv/autophagy-skills/live/mail/scripts/…` 로 바뀌었고 「실행 경로 규칙」 절이 미러·자가 루트 경로를 명시적으로 금지한다.

## 사용 시나리오
1. **(거부)** 에이전트가 습관대로 `/srv/autophagy-agents/skills/mail/scripts/triage_cli.py draft …` 를 실행 → `GATE-REFUSED STALE-SKILL-COPY-BLOCK: mail 은 관리자 배포본 /srv/autophagy-skills/live/mail/scripts/triage_cli.py 에서만 실행한다 — …` (exit 3), 초안 없음, 메일도 읽지 않음 → 에이전트가 안내된 경로로 다시 실행.
2. **(정상)** `/srv/autophagy-skills/live/mail/scripts/triage_cli.py draft --uid … --instruction …` → 원문 인용이 붙은 초안이 승인 스레드에 게시된다.
3. **(읽기)** 낡은 사본으로 `mode` 를 물으면 그대로 답한다 — 외부효과가 없다.
