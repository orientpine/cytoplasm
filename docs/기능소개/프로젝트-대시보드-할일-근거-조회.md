# 프로젝트 대시보드 — 카드 승인 할 일 근거 조회

## 무엇을
노드 문지기가 대시보드 할 일 하나의 승인 출처와 카드 좌표를 조회하고, 쓰기 근거로 사용한 횟수와 첫 시각을
별도 기록한다. 기존 지시 조회와 같은 전용 키·루프백 경계를 쓰며 할 일 제목 대신 SHA-256만 돌려준다.

## 왜
소유자 2026-11-03 06:09 KST Q2: "고친다: 카드 승인 할 일도 근거로 받음 (따로 PR, 추천)".
자동으로 반영된 할 일을 카드 승인으로 오인하지 않으면서, 이미 승인한 할 일의 근거를 문지기가 확인할 수 있어야 한다.
이 API는 조회·기록만 하고, 허용 판단은 문지기(dori-gate `X-Dori-Owner-Todo`)와 노드 게이트(유돌 `--origin-todo`,
[소개](유돌-할일-근거-첨부-저장.md))가 한다. 응답의 `source`(종류·id)로 노드 게이트가 그 할 일의 근거 메일만 읽게 묶는다.

## 사용 시나리오
- 소유자가 제안 카드에 승인한다 → 보드에 할 일과 그 카드 메시지 참조가 저장된다 → 문지기가
  `GET /api/todos/<todo_id>`를 부르면 `auto_applied: false`와 일치하는 카드의 채널·메시지 좌표를 받는다.
  문지기는 카드 근거를 확인한 뒤 `POST /api/todos/<todo_id>/use`로 사용 한 번을 남긴다.
- 자동 반영된 할 일은 `auto_applied: true`, `card: null`이다. 제안 레코드가 없거나 메시지가 다르거나
  채널이 비면 카드 좌표는 없다. 소유자 승인 여부를 추측하지 않는다.
- 잘못된 키·키 없음·테일넷 요청은 403, 잘못된 형식이나 없는 할 일은 404다. 실패 요청은 사용 기록을 만들지 않는다.
- 조회만 하면 횟수와 파일은 바뀌지 않는다. 사용 기록은 `orders.db`의 `todo_uses`에 남고 보드 스키마는 바뀌지 않는다.
