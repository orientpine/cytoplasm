# 토큰 없이 설치 완주 · 소유자 확인 절차

## 무엇을

`DISCORD_BOT_TOKEN`이 설치기 환경에 없으면 `discord-readiness` 체크가 **경고(WARN)**로 남고
설치는 계획 끝까지 진행한다. 그리고 설치가 끝날 때, 설치기가 **판정하지 못한 항목**의
확인 명령을 「소유자 확인 절차」로 함께 출력한다.

## 왜

`discord_check.py`는 서로 다른 두 가지를 종료코드로 구분한다 — `rc=1`은 "검사했고 전제가
충족되지 않았다", `rc=2`는 "토큰이 환경에 없어 **아무것도 검사하지 못했다**"이다. 설치기는
둘을 `FAIL`로 접었고, 계획 적용은 첫 FAIL에서 멈추며, 이 체크는 계획 앞쪽(50개 중 2번째)에
있었다. 결과적으로 배포키 생성·등록 안내·gitleaks·체크아웃·자산 파일·심링크·healthcheck
프로브·타이머·신뢰키 검증·최종 healthcheck가 **전부 실행되지 않았다.**

`sudo`는 환경변수를 지우므로 이 상황은 사고가 아니라 정상 경로이고,
`docs/guide/install.md` §6은 이미 "Discord 전제는 설치 자체의 전제가 아니다"라고 적고
있었다. 산문이 맞고 코드가 틀렸다 — 2026-09-07 외부 설치자가 밟은 자리다.

경고로 낮춰도 종료 게이트는 그대로 엄격하다. `checks.exit_code`는 WARN으로 종료코드를
바꾸지 않으므로, **판정해서 나온 실패(rc=1)는 예전처럼 설치를 세운다.**

## 사용 시나리오

**완주 경로.** 토큰을 올리지 않고(또는 `sudo`가 지운 채로) 설치한다.

```
[PASS] hermes-gateway: agent and peer Hermes gateways are active
[WARN] discord-readiness: TOKEN-ABSENT: DISCORD_BOT_TOKEN이 설치기 환경에 없어 판정하지 못했다 …
[PASS] GenerateDeployKey: converged
…                                          ← 예전에는 여기부터 전부 실행되지 않았다
--- INSTALLED: 51건 중 실패 0 / 경고 2
소유자 확인 절차 — 설치기가 판정하지 못한 항목이 있다:
- discord-readiness: 이 노드에서 직접 확인한다.
    set -a; . ~/.env.secrets; set +a
    python3 automation/install/discord_check.py --config /home/agent/.hermes/interop/config.json
  rc=0이면 전제가 충족된 것이다. 승인 카드가 실제로 도착하는지는 봇과의 DM에서 확인한다 …
```

명령에는 **이 설치의 `--config` 경로가 박혀 있다** — 소스를 읽어 복원하지 않아도 된다.
설치 마법사로 설치해도 같은 블록이 마지막 화면에 그대로 나온다.

**거부 경로.** 토큰은 닿았는데 인텐트가 꺼져 있거나 권한·채널이 모자라면 `rc=1`이고, 그것은
예전 그대로 `[FAIL] discord-readiness: discord_check.py rc=1`로 설치를 세운다. 문구도
바이트 그대로다 — `install.md` §8의 증상 표가 그 문자열을 인용한다.

**절차를 적어 두지 않은 경고도 이름이 나온다.** 실측에서 `trust-key.fingerprint` 경고가
같은 블록에 자기 사유와 함께 실렸다. 제목만 있고 항목이 없는 블록은 "남은 일이 없다"로
읽히기 때문이다.

## 관련

- 판정·렌더의 단일 정의: `automation/install/owner_actions.py`
  (`discord_readiness` · `follow_up` · `FOLLOW_UP_HEADING`)
- 배선: `automation/install/executor.py`(판정) · `installer.py`(출력) ·
  `wizard_screens.py`(마법사 요약이 블록을 삼키지 않도록)
- 회귀: `tests/unit/test_install_token_absent.py`
- 절차 문서: [install.md](../guide/install.md) §6·§8
- 실측 증적: [docs/qa/INSTALL-TOKEN-WARN/](../qa/INSTALL-TOKEN-WARN/) — 컨테이너 하네스가
  계획 50/50 항목에 도달한다(이전 상한: 2/50).
- 승인 게이트는 건드리지 않았다. 이 변경은 **설치 시점의 전제 판정**만 다루며,
  승인 표면·게이트·리액션 판정은 그대로다.
