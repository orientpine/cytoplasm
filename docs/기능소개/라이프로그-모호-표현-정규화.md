# 라이프로그 모호 표현 정규화 — 근거 없는 호칭이 파일명·담당자로 굳지 않게

## 무엇을

라이프로그 노트를 만들 때 **누구인지·어디인지 복원할 근거가 없는 표현**(`사람 형님`, `그분`,
`거기`, `미상`, `화자2`)을 노트에 새기지 않는다. 판정은 추출 경계 한 곳(`parse_extraction`)에서
결정론적으로 일어나고 세 자리에 걸린다 — **노트 제목**(→ 파일명), **사람·장소 목록**, **할 일의 담당자**.
같은 티켓의 나머지 절반으로 **승인 카드 미리보기가 요약을 먼저·더 많이** 보여준다(5줄·160자 → 7줄·190자,
전사 폴백은 요약과 한눈에가 **둘 다** 없을 때만).

## 왜

수리 티켓 t_35e8a91c(2026-09-08 소유자): "기록 시 '사람 형님'처럼 문맥상 의미가 불분명한 표현을
그대로 남기지 않도록 하고, 모호한 표현은 제외하거나 명확한 의미로 정규화해 주세요. 결과 화면에서는
원문성 잡음보다 핵심 요약이 더 많이 보이도록 요약 표시 비중과 길이를 늘려 주세요."

같은 날 새벽 `한눈에` 에서 `사람::`·`장소::`·`한 줄::` 을 걷어낸 뒤(오인식을 위키링크로 굳혔기
때문), **남은 피해 경로는 세 곳**이었다. 가장 해로운 것은 제목이다 — 추출된 제목이 노트 이름이자
**vault 파일명**이 되므로 잘못 들은 호칭 하나가 영구히 얼어붙는다. 담당자(`담당 …`)는 결정·할 일
줄에 그대로 찍히고, 사람·장소는 렌더되지 않더라도 저장·용어교정을 계속 통과한다.
**요약 산문은 모델이 쓰는 글**이라 사후 치환으로 고치면 문장이 망가지므로, 그쪽은 코드가 아니라
프롬프트(v5)가 맡는다.

## 사용 시나리오

1. **happy**: 전사본이 `사람 형님` 이라 들은 녹음 → 추출이 제목·사람·담당자에서 그 표현을 떨어뜨리고
   `김철수 박사`·`판교 사무실` 같은 근거 있는 값만 남긴다 → 제목이 비면 녹음 자신의 이름(그것도
   글자가 없으면 시각 기반 기본값)이 노트 이름이 되므로 **모호한 호칭이 파일명에 들어가지 않는다**.
2. **이름이 붙은 호칭은 지킨다**: `김철수 형님` 은 앞에 실명이 있으므로 그대로 둔다. 규칙은 실명
   사전이 아니라 **식별 근거의 유무**만 본다.
3. **승인 카드**: 요약이 있는 녹음은 미리보기 7줄이 전부 요약에서 나오고 전사 잡음은 한 줄도 섞이지
   않는다. 요약과 한눈에가 **둘 다** 비었을 때만 `[전문 발췌 · 요약 없음]` 라벨을 한 줄 쓰고 전문을
   인용한다 — 폴백임을 스스로 밝힌다.
4. **실패 경로**: 판정할 수 없는 값은 추측해서 복원하지 않고 **버린다**. 규칙층은 예외를 던지지
   않으므로 이상한 응답 하나가 녹음 전체를 얼리지 못한다. 카드가 1900자를 넘으면 예전처럼 자르지 않고
   게시를 막는다(fail-closed).

## 관련

- 규칙층: `automation/plaud_sync/lifelog_extract.py` `_reference()` — 친족 호칭·직함·일반명사·지시어
  집합과 거부 정규식(미상/미정/화자N/템플릿 빈칸·깨진 글자)을 **규칙별로 분리**해 두어 왜 떨어졌는지
  읽을 수 있다. 조사가 붙은 형태(`형님과`·`그분과의`)도 같은 판정을 받는다. 적용 자리는
  `title`·`_strings`(people·places)·`_todos` 의 `owner` 셋뿐이고 **요약·전사 산문에는 걸지 않는다**.
- 프롬프트: `prompts/lifelog-extraction-v5.md` — v4 지시를 그대로 보존하고 제목·요약 산문에서 근거
  없는 인물 표현을 빼라는 규칙만 덧붙인다. v4 는 동결이고 추가 모델 호출은 없다.
  로더 상수는 `automation/plaud_sync/lifelog_extract_live.py` 한 줄.
- 카드: `automation/plaud_sync/render.py` — `PREVIEW_LINES` 5→7, `PREVIEW_LINE_CHARS` 160→190,
  선택 순서가 v3 의 한눈에→요약에서 **요약→한눈에** 로 뒤집혔다. v3 렌더·미리보기는 별도 함수로
  동결 보존되고 `action_hash` 바인딩은 불변이다. 승인 요청 표시 쪽은
  [옵시디언 노트 승인 요청 표시](옵시디언-노트-승인-요청-표시.md).
- 되돌리지 않은 것: `한눈에` 의 `사람::`·`장소::` 줄은 그대로 없다. 이름은 요약 본문이 말한다는
  2026-09-08 결정을 유지한 채, 그 본문에 근거 없는 호칭이 들어가지 않게 하는 것이 이 변경이다.

  `tests/unit/test_plaud_sync_render.py`.
