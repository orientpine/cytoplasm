# 프로젝트 대시보드 첫 사용 안내와 오류 화면

## 무엇을
대시보드가 비어 있을 때와 무언가 잘못됐을 때를 제품답게 보여 준다. 처음 연 사람에게는 데이터가 들어오는 세 단계를 안내하고,
체크 저장이 실패하면 경고창 대신 그 줄 아래에 이유를 적는다. 보관은 확인 대화상자로 묻고, 접속 키가 없거나 없는 주소를
열면 영어 평문 대신 같은 모양의 안내 화면이 나온다. 제품 이름은 설정 `dashboard.brand` 로 바꾼다.

## 왜
2026-10-16 소유자 지시 "프로젝트 대시보드 ui를 개선해서 판매용으로 만들어줘." 이전에는 빈 보드가 문장 한 줄과 0 칸뿐이었고,
저장 실패는 `alert('기록하지 못했습니다')`, 보관 확인은 브라우저 기본 확인 창이었으며, 401·404는
`authentication required — open the URL with ?t=<token> once` 같은 영어 평문이었다.

## 사용 시나리오
- 새 기관에 설치한 직후 대시보드를 열면 「처음 오셨군요」 안내가 세 단계를 보여 준다. 데모 명령으로 지어낸 보드를 띄워 둘러볼 수 있다.
- 휴대폰에서 할 일을 체크했는데 연결이 끊기면 체크가 되돌아가고 그 줄 아래에 「연결이 끊겨 저장하지 못했습니다」가 나온다. 다시 누르면 된다.
- 끝난 프로젝트에서 「보관」을 누르면 무엇이 바뀌는지 설명하는 대화상자가 뜬다. 「취소」 또는 Esc 로 닫고, 「보관하기」로 진행한다.
- 공유받은 사람이 접속 키 없이 주소를 열면 「로그인이 필요합니다」 화면이 처음 한 번은 설치 때 받은 주소로 열라고 안내한다.
- 설정에 `{"dashboard": {"brand": "가상연구소 과제 현황"}}` 을 두면 머리·탭 제목·폰 홈 화면 이름·메일 사본·오류 화면의 이름이 바뀐다(아이콘은 이름과 상관없는 그림, [팔란티르](프로젝트-대시보드-팔란티르.md)). 40자를 넘으면 설정 읽기가 거부된다.
