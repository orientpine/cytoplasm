# 회의록 문서별 비민감 검토

## 무엇을·왜

민감 키워드의 오탐 한 건을 소유자가 문서 전체 검토로 확정했다면, 전역 키워드 규칙을 느슨하게 하지 않고 **해당 게이트 입력 한 건**의 후속 분류만 정정한다. 검토되지 않은 모든 문서는 기존 게이트를 따른다.

## 사용 시나리오

- 운영자는 최초 ingest의 개인 0600 로그에서 해당 실행의 `review_sha256`을 확인한다. 소유자가 전사본과 함께 사용한 근거·슬라이드·자동 참고자료까지 확인하고 비민감이라고 결정한 뒤, root 운영자가 체크아웃 밖 고정 경로에 신원·사유·검토일·범위를 기록한 영수증을 설치한다. 같은 입력의 재인제스트는 여전히 보수적인 민감 LLM 경로로 추출하되, 태그 없는 회의록을 만들고 일반 회의의 발행 경로를 사용한다. 원문 부록은 보존된다.
- 자료가 하나라도 변경되거나 영수증이 없거나 신뢰할 수 없으면 이전 승인으로 발행하지 않고 기존 민감 경로를 유지한다. 철회는 root 운영자가 영수증을 제거한다.

`meeting-downstream` 범위는 **Drive 전용이 아니다**: 프로젝트 원장·카드·마일스톤·#team·결과 통지도 포함된다. 검토 전 모든 표면을 고려해야 한다. Drive 발행은 별도 옵트인과 기존 파사드에 따르며, 배포 없이 이 기능은 실행되지 않는다.
