# 일정 카드 선택과 날짜 읽기

## 무엇을
유돌이 형 일정을 넣을 때 `calendar-request --card` 로 일정 초안 카드를 올릴 수 있다. 그리고
`11/25(수) 오후 4시부터 5시까지`, `16:00-17:00`, `12월 9일(수)~10일(목)` 같은 형의 표기를 한 번에 읽는다.

## 왜
- 형이 "일정 추가는 카드 올려"(2026-10-30)라고 했는데, 형 글이 근거로 붙은 요청은 Q233 스위치 때문에 늘 카드 없이
  바로 들어갔다. 카드로 올릴 길이 없었다.
- 유돌의 `--text` 가 `11/25(수)` 와 `오후 4시부터 5시까지` 를 못 읽고 되물었다(`5시`의 오전/오후를 다시 물음).
- `12월 9일(수)~10일(목)` 은 날짜 뒤 `(수)` 때문에 끝 날을 놓쳐 9일 하루만 들어갔다("일정 달력에는 10일은 왜 빠져있어?").

## 사용 시나리오
1. 형: "11/25(수) 오후 4시부터 5시까지 자문회의, 일정 추가는 카드 올려" → 유돌:
   `calendar-request --card --text "11/25(수) 오후 4시부터 5시까지 자문회의"` + 형 글 좌표 → 일정 초안 카드
   (`2026-11-25 (수) 16:00 ~ 17:00 KST`)가 올라오고 유돌이 그 스레드 링크를 답한다 → 형 ✅ → 캘린더에 들어간다.
2. 형이 카드를 말하지 않으면 `--card` 없이 보낸다 → Q233 그대로 카드 없이 바로 들어가고 21:30 요약에 남는다.
3. `12월 9일(수)~10일(목) 워크숍` → 9·10일 이틀 종일 일정(카드면 `2026-12-09 (수) ~ 2026-12-10 (목) 종일`).
4. 거절·되묻기: `11/26(수) 오후 2시` 는 11/26이 목요일이라 어느 쪽도 고르지 않고 "11월 26일은 목요일인데 (수)로 적혀
   있어요…"로 되묻는다. 여러 날 범위에 시각까지 붙거나, 날짜 하나에 시각도 `종일`도 없으면 되묻는다.

## 관련
- 게이트: `automation/yoodori_gate/yoodori_read_gate.py` `card_choice`(`--card` 는 `calendar-request` 에서 한 번만,
  다른 명령엔 거절). 카드 경로는 기존 `draft-create` → `post-confirm` 그대로, 승인은 형 ✅.
- 파서: `skills/calendar/scripts/calendar_core.py` (M/D, 요일 표시 검사, 끝 시각 오전/오후 이어받기, 범위·`종일` 종일 일정).
- 유돌 역할 지침 `dori/roles/yoodori/AGENTS.md.tmpl`, 스킬 `skills/calendar/SKILL.md` 「시간 파싱 규칙」.
- Q233 기본(카드 없이 바로)은 바꾸지 않았다. 선택만 더했다.
