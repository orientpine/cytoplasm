# 받는 사람이 여러 명인 메일을 한 카드로 올린다

## 무엇을

유돌 게이트 `mail-compose` 와 메일 스킬 `compose` 가 `--to` 를 `--cc`·`--bcc` 처럼 여러 번 받는다. 주소마다 `--to` 하나,
게이트는 주소 하나하나를 예전 한 명일 때와 같은 검사(메일 주소 하나)로 보고, 스킬은 순서대로 받는 사람 칸 하나(`a, b, …`)에
넣는다. 카드에 받는 사람 전부가 보이고 그 값이 초안 해시에 묶여, 형 ✅ 뒤에만 그대로 나간다.

## 왜

형이 받는 사람 다섯 명을 모두 받는 사람 칸에 넣은 메일을 시켰는데, 게이트가 두 번째 `--to` 를 "unknown or repeated flag",
쉼표로 묶은 주소를 "one email address required" 로 거절했다(2026-11-03 유돌 수리 요청). 스킬 `compose` 도 `--to` 를 한 번만
받아, 여러 번 주면 마지막 주소 하나만 남기고 나머지를 말없이 버렸다.

## 사용 시나리오

- **다섯 명에게**: 형 "이 다섯 분께 노트북 자산 확인 메일 보내" → 유돌 `node-read mail-compose --to <1> --to <2> … --to <5>
  --subject … --body-b64 …` + 형 글 좌표 → 형 스레드 카드의 받는 사람 줄에 `<1>, <2>, <3>, <4>, <5>` 다섯 주소 → 형 ✅ → 기존 메일 watch 가
  다섯 명이 받는 사람인 메일 한 통을 보낸다.
- **한 명**: 예전과 같다(게이트가 만드는 명령 줄도 바이트 그대로).
- **같은 주소 두 번**: 대소문자가 달라도 한 번만 들어간다.
- **거부**: 쉼표로 묶은 `--to`, 메일 주소가 아닌 `--to` 가 하나라도 있으면 게이트가 카드 없이 거절한다. Gmail 답장
  (`--reply-gmail`)은 받는 사람을 원메일이 정하므로 `--to` 를 계속 거절한다.
- **⛔ 또는 무응답**: 아무것도 나가지 않는다.

## 관련

- 게이트 `automation/yoodori_gate/yoodori_read_gate.py`(`_REPEATABLE` 에 `--to`, 요청 전체 64칸 한도는 `--bcc` 와 같음),
  스킬 `skills/mail/scripts/triage_cli.py`(`compose --to` 반복 → `_joined_to`).
- 받는 사람 칸 하나에 쉼표로 이어 쓰는 모양은 기존 그대로라 카드·해시·발송(mailon 이 `a, b` 를 나눔)·승인 표면 감사
  (`approval_surface_audit`)·승인 KPI(`approval_kpi`)는 바뀌지 않는다. 새 카드 종류·워처 없음.
- 승인: 바깥으로 나가는 메일이라 형 ✅ 카드 뒤에만 나간다. 시험 `tests/unit/test_yoodori_gate.py`·
  `tests/unit/test_mail_compose_gate.py`.
