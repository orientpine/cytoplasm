# 그림자 스킬 2분 탐지 — self→governed 선점 경보를 하루에서 2분으로

## 무엇을

에이전트가 배포 스킬과 같은 이름의 자가 스킬을 만들면(예: `recall`), 기존
`supply_chain_watch` 2분 틱이 이름 대조만으로 그것을 잡아 소유자에게 즉시 알린다.
새 워처는 없다 — 같은 틱에 저비용 검사 하나가 편입됐을 뿐이다.

## 왜

Hermes의 충돌 검사(`_find_skill`)는 governed 심링크 팜을 따라가지 못해 이 선점을
사전에 막지 못하고(2026-08-16 실측), 1차 루트가 발견에서 이기므로 선점된 순간부터
**승인 게이트를 강제하는 배포본이 가려진다**. 지금까지의 유일한 경보는 일 1회
`selfskill_audit` 아침 보고였다 — 노출 창이 최대 하루였다. 이 틱은 그 창을 2분으로
줄인다(아침 보고는 그대로 남는다 — 대체가 아니라 지연 단축).

## 사용 시나리오

### 탐지 경로

1. 에이전트가 `~/.hermes/skills` 아래(깊이 1·2, 번들 제외 — 일 1회 감사와 같은 기준)에
   governed 이름과 겹치는 스킬을 만든다.
2. 다음 2분 틱이 `SHADOWS-GOVERNED <이름>` 통지 1건을 보낸다 — 조치 안내
   (`hermes curator archive <name>` 또는 이름 변경) 포함.
3. 해소될 때까지 매 틱 저널에 한 줄이 남고, 통지는 반복되지 않는다(신호 보존).
4. 해소 후 같은 이름이 다시 나타나면 새 사건으로 다시 알린다.

### 실패 경로

- 통지 전송 실패: 상태가 전진하지 않아 다음 틱이 같은 통지를 재시도한다(at-least-once).
- 탐지 자체가 실패: `shadow-check-error` 한 줄만 남기고 틱은 계속된다 — 그림자 검사가
  승인 재개(공급망 워처의 본업)를 세우면 안 된다.
