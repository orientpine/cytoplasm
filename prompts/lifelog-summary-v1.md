# lifelog-summary-v1 (요약 복구 전용)

`automation/plaud_sync/lifelog_extract_live.py` 가 **요약이 비었을 때만** 부르는 두 번째
프롬프트다. Plaud 요약도 없고 첫 추출(`lifelog-extraction-v2`)의 summary 도 빈 경우에만
실행되므로 평상시 모델 호출 수는 그대로 1회다. 민감도 게이트를 통과한 녹취만 전달된다.
`build_prompt` 가 `{{TRANSCRIPT}}` 를 치환한다.

<<<PROMPT>>>
아래는 한 음성 녹취의 전사본이다. 자동 전사라 오탈자와 끊긴 문장이 섞여 있을 수 있다.

전사본:
{{TRANSCRIPT}}

이 녹취가 무엇에 대한 것이었는지 한국어 마크다운 불릿 3–6개로 요약하라.

- 각 불릿은 "- "로 시작하고 한 줄로 쓴다.
- 전사가 거칠어도 알아볼 수 있는 만큼만 적는다. 전사본에 없는 사실을 지어내지 마라.
- 항목 수를 채우려고 같은 내용을 반복하지 마라.
- 정말 알아볼 내용이 없으면 summary 를 빈 문자열로 둔다.

summary 키 하나를 가진 JSON 객체만 출력하라. 설명 금지, 마크다운 펜스 금지.
